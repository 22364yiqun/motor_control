# Results and Media

This directory separates presentation media from reproducible experimental evidence.

- [`media/`](media/) contains all project images and demonstration videos.
- [`experiments/`](experiments/) is reserved for raw logs, measurement tables, plots, test procedures, and analysis scripts.

Short videos demonstrate that a function was exercised on the shown prototype. They do not by themselves establish tracking accuracy, bandwidth, calibrated torque, thermal limits, efficiency, reliability, or a safe operating envelope. Quantitative claims should be accompanied by the hardware revision, firmware commit, supply settings, load, instruments, sample count, procedure, raw data, and analysis method.
