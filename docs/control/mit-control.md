# MIT 控制说明

当前固件已移除标准“位置环 → 速度环 → 电流环”外环，只保留 MIT 风格的 PD 力矩控制：

```text
tau_out   = Kp × pos_err + Kd × vel_err + tau_ff
tau_motor = tau_out / (N × eta)
Iq_ref    = tau_motor / Kt
Id_ref    = 0
```

- `N`：减速比，定义为电机转速/输出轴转速；直驱为 1。
- `eta`：传动效率，范围 0～1。
- `Kt`：电机力矩常数，单位 N·m/A。
- `tau_ff`：输出端前馈力矩，单位 N·m。

固件还会执行位置误差、速度误差、输出力矩和 `Iq` 限幅，并在一定位置误差范围内提供静摩擦补偿。对应宏均位于 `source/motor/config.h`。

| 状态 | 值 | 含义 |
| --- | ---: | --- |
| `ADC_OFFSET` | 0 | 三相电流零点采样 |
| `ALIGN` | 1 | 转子电角度对齐 |
| `MIT` | 2 | 闭环 MIT 控制 |
| `FAULT` | 3 | 故障，关闭输出 |

调参原则：响应太软时，在确认电流环稳定后小幅增加 `Kp`；到位抖动时增加 `Kd` 或降低 `Kp`；一给命令就冲击时，先降低力矩/电流限幅，再检查编码器方向、减速比与 `Kt`。完整流程见 [调参与标定](../tuning/README.md)。
