# Assembly Guide (To Be Released)

This directory will contain a reproducible procedure from incoming-parts inspection through final acceptance testing. Planned coverage includes required tools and safety precautions, PCB inspection, mechanical assembly, second-encoder air gap/alignment/zero position, wiring and interfaces, fastener torque, and current-limited first-power-up checks.

Each release should identify the compatible PCB and mechanical revisions and include clear photographs or section views for critical steps.
